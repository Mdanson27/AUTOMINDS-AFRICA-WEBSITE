# AutoMinds Africa Website

Interactive company website for AutoMinds Africa, designed as an original operating-system-inspired experience using the company palette: electric blue, orange, white and deep navy.

## Included

- Editorial hero and live company console
- Animated Kampala/Africa signal rail
- Interactive AutoMinds operating-system workspace
- AI, Smart Identity, Build Lab and Growth System modules
- Interactive terminal commands
- Product/system explorer
- Workflow and delivery process
- Full 9-person team section
- WhatsApp, email, phone and website contact actions
- Responsive desktop/tablet/mobile layouts
- GitHub Pages deployment workflow

## GitHub Pages

The repository contains `.github/workflows/pages.yml` using the official GitHub Pages deployment actions.

For the first deployment, GitHub Pages must be enabled once under:

`Settings → Pages → Build and deployment → Source → GitHub Actions`

After that, each push to `main` automatically republishes the site.

Expected project Pages URL:

`https://mdanson27.github.io/AUTOMINDS-AFRICA-WEBSITE/`
