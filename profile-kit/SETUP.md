## After copying

1. Make the repository **Public**.
2. Ensure the default branch is **main**.
3. Open **Actions** and run **Update contribution neural grid** once.
4. Confirm `assets/neural-contributions.svg` changes from the placeholder to the live contribution grid.
5. On your GitHub profile, choose **Customize your pins** and select the six showcase repositories.
